# CS 230 — Operating Platforms Portfolio

## Project Summary

The Gaming Room was a client that wanted to expand its existing Android game, Draw It or Lose It, so players could access it from multiple operating systems. The game involves teams competing to guess images within a time limit. The client needed a solution that would support multiple users, manage game sessions, prevent duplicate game and team names, and provide reliable performance across different devices. My role was to help design a software solution that would meet these requirements.

## What I Did Well

I think I did particularly well at comparing different operating systems and explaining why Linux would be a good choice for hosting the game server. I also considered important factors such as memory management, storage, security, and network communication. I tried to make my recommendations clear and connect them to the client's actual needs rather than just describing the technology.

## How the Design Document Helped

Working through the software design document helped me better understand how planning connects to programming. Before writing or modifying code, it is important to understand how the different components should work together. For example, identifying the relationships between games, teams, and players helped explain how the application should be organized. It also helped me understand why design patterns, such as the singleton pattern, can be useful when managing shared application resources.

## What I Would Improve

If I could revise one part of my work, I would spend more time expanding the distributed systems section. Although I explained how different devices could communicate with a central server, I think I could improve it by including more specific examples of how the application would respond to network interruptions or server outages. I would also consider adding a diagram to make those connections easier to understand.

## Understanding the User's Needs

I approached the client's requirements by identifying what the game needed to accomplish and how players would interact with it. Since The Gaming Room wanted the application to work across multiple platforms, I recommended a web-based approach with a Linux server. I also considered the importance of protecting user information and maintaining game performance. Understanding user needs is important because a software application can function correctly from a technical perspective but still fail if it does not meet the expectations of the people using it.

## My Approach to Software Design

My approach involved reviewing the requirements, identifying the application's major components, comparing possible operating platforms, and considering how those components would communicate. I also looked at how storage, memory, security, and scalability could affect the application's performance. In future projects, I would continue using design documents and diagrams to organize my ideas before development. I would also spend more time considering potential problems early in the design process so they can be addressed before they become larger issues.
